# Синхронизация

## Идентичность и формат

Сопоставление выполняется по положительному 64-битному ID из SharedTableData, а не по номеру строки или ключу. Имя ключа можно менять, строки можно переставлять. ID нельзя редактировать после выпуска ссылок. Google хранит ID как текст: большие целые числа в числовой ячейке теряют точность. Запись через OAuth использует stringValue, поэтому текст, начинающийся с `=`, не превращается в формулу.

По умолчанию A = ID, B = Key, C = en, D = ru. В mapping задаются номера колонок, язык и коллекция; одна вкладка соответствует одной коллекции. Можно использовать несколько mapping assets. Синхронизация запускается по одной коллекции, у каждой собственный baseline и журнал.

При импорте стандартного Unity Google Sheets Extension ID читается из примечания Key cell, как в официальном KeyColumn. Дополнительные пользовательские SheetColumn не копируются автоматически. Кнопка переноса mapping не переносит секреты в SO и не меняет исходный extension.

Примечания языковых ячеек могут содержать служебные метки `[EasyLocalization:missing]`, `[EasyLocalization:smart]`, `[EasyLocalization:plain]`. Остальной текст примечания сохраняется. CSV примечания не передаёт.

## Что показывает preview

- **Added**: ID есть только в источнике, строка будет добавлена.
- **Renamed / Changed**: ключ или переводы отличаются; рядом показаны обе версии.
- **Conflict**: обе версии строки изменились относительно последнего подтверждённого обмена, либо это первое сравнение разных существующих строк. Выберите **Use source row** или **Keep target row**. Разрешение применяется к целой строке со всеми сопоставленными языками.
- **MissingOnSource**: в источнике нет строки. По умолчанию цель сохраняется. Отметка **Delete target row explicitly** разрешает удаление. Удаление Unity shared key удаляет записи во всех языках коллекции, включая несопоставленные.

Пустой перевод, отсутствующий перевод и отсутствующая строка различаются. Пустой перевод переносится как пустая строка. Отсутствие строки не считается разрешением удалить её. Осознанный Keep target сохраняется в baseline и не предлагается повторно до следующего изменения.

Проверяются ID, ключи, соответствие колонок языкам, наличие таблиц, синтаксис Smart Strings и совпадение набора селекторов параметров между Smart-переводами. Пустые/отсутствующие переводы показаны как предупреждения. Синтаксис и набор параметров не доказывают корректность runtime-типов аргументов или всех веток formatter: проверяйте реальные значения в игре. Формулы в сопоставленных Google-ячейках не поддерживаются — нужны текстовые значения.

## Применение и сбои

Перед Apply повторно читаются Google и Unity, проверяется fingerprint mapping и данных. Изменённые после preview данные возвращают новый план; предыдущие решения сбрасываются. Изменение подключения во время сетевого запроса останавливает операцию и требует нового Preview: текущий запрос нельзя перенаправить на другую таблицу. Перестановка строк сама по себе не меняет смысл плана, а физические позиции перечитываются перед записью.

Unity изменяется через публичный API таблиц, с Undo и сохранением существующих metadata. При перестановке имён ключей используются временные уникальные имена; существующие ID сохраняются. Ошибка применения откатывает всю локальную операцию.

Google получает один `spreadsheets.batchUpdate` по сопоставленным ячейкам. Несопоставленные колонки и оформление не перезаписываются. При удалении очищаются сопоставленные ячейки, физическая строка остаётся. Используйте отдельную вкладку для переводов. Лимит первой версии — 20 000 изменяемых ячеек в одном batch; большее изменение нужно разбить. Maximum Rows проверяется до чтения, чтобы не принять обрезанный результат за удаления.

Перед изменением сохраняется локальный журнал в `Library/EasyLocalization/journal-*.json`. Baseline обновляется только после подтверждения результата. Отмена, закрытие окна, тайм-аут или потерянный ответ оставляют журнал. Следующий Preview сверяет фактическое состояние: уже выполненная запись подтверждается без повторной отправки, частичный/отличающийся результат показывается заново. Не удаляйте Library до проверки прерванной отправки.

Чтение имеет тайм-аут 45 секунд и максимум три попытки с ограниченной задержкой. OAuth-вход ждёт до трёх минут. Неопределённая запись не повторяется автоматически: сначала новый Preview. CSV-ответ ограничен 4 МБ. Удаление Library требует повторного подключения Google.

## Ограничение одновременного редактирования

Google Sheets не предоставляет этому API атомарную операцию «запиши, только если все прочитанные ячейки ещё прежние». Между последним чтением и batch остаётся сетевое окно. Не редактируйте те же ячейки во время Apply. После отправки пакет читает результат ещё раз и не подтверждает отличающийся результат; это не устраняет саму возможность конкурентного редактирования Google.
