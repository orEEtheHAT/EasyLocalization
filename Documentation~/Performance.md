# Измерения 0.1.0

12 ноября 2026, Unity 6000.3.22f1, Windows Development player, отдельный чистый проект. Запуск `-batchmode -nographics`, шесть прогревочных переключений и 20 измеренных переключений en/ru. Каждый подписчик — настоящий LocalizedText с параметром `{0}` и UnityEvent<string>. В ожидании нет покадрового опроса текста.

| Подписчики | Синхронная часть вызова на главном потоке, среднее мс | До обновления всех текстов, среднее мс | GC Alloc за измеренные кадры / переключение | Managed memory до / после, МиБ |
|---:|---:|---:|---:|---:|
| 100 | 0,50 | 1,89 | 233 413 байт | 1,96 / 2,34 |
| 1 000 | 4,65 | 13,81 | 2 154 151 байт | 8,78 / 10,59 |
| 5 000 | 20,76 | 63,56 | 10 690 551 байт | 47,92 / 86,72 |

Синхронная часть измерена Stopwatch вокруг вызова SetLanguageAsync и отмечена CPU marker `EasyLocalization.SwitchCall`. Полное время включает асинхронные callbacks и форматирование всех подписчиков. GC измеряется **Unity ProfilerRecorder / GC Allocated In Frame**, сумма за измеренные кадры делится на 20. Это включает служебные выделения player между callbacks; это не обещание точного allocation budget одной функции. До измерений выполняется GC, после измерений — обычный снимок managed memory без принудительного GC; значения не доказывают утечку.

Измерение не включает Canvas layout, текстовые меши и GPU-отрисовку: у подписчиков есть выходной UnityEvent, но нет 5000 визуальных Text. Не переносите эти результаты напрямую на FPS реального меню. На этом ПК массовое обновление 5000 текстов заметно дороже кадра; для больших интерфейсов держите включёнными подписчиков видимых окон и обновляйте аргументы по изменениям данных. Это не сценарий без выделений памяти.

Jobs/Burst не добавлены: измеряемый путь использует Unity Localization, управляемые строки, форматирование и UI-события на главном потоке. Сетевые операции выполняются только Editor-кодом и в runtime-замер не входят.

Воспроизведение — [Tools~/README.md](../Tools~/README.md). Исходник измерения `Tools~/Verification/Runtime/LocalizationVerification.cs` сохраняет JSON с проверками, количеством кадров GC, временем и памятью. В рабочем проекте исходный отчёт находится в `Audits/EasyLocalization/clean-performance.json`.
